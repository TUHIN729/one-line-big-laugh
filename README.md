# One Line, Big Laugh

A [make.fun](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) entry: one hilarious line, 200 characters or fewer, that lands entirely on its own. A stand-up-comic judge compares lines head-to-head — funniest wins.

The line:

> I asked my smart speaker to play something relaxing, so it read my search history aloud in a spa voice.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (103 characters, UTF-8).

Requires Node 22.18 or later. The program is deterministic: the line is embedded in `main.ts`, and the output is validated to 1–200 characters before writing.
